# 企业实习总结报告 Typst 模板

电子科技大学信息与软件工程学院企业实习总结报告模板。支持中英文摘要、章节目录、图表代码自动编号、GB/T 7714 参考文献格式。

## 文件结构

```
├── main.typ               # 入口文件，导入所有模块
├── utils.typ              # 公共函数：字体、页眉页脚、图表代码编号
├── cover.typ              # 封面
├── abstract.typ           # 中英文摘要
├── content.typ            # 正文（含样式示例，可删除）
├── acknowledgements.typ   # 致谢
├── refs.bib               # 参考文献（BibLaTeX 格式）
├── images/
│   └── 电子科技大学-logo-512px.png
└── .gitignore
```

## 使用说明

### 全局设置

在 `main.typ` 中可调整：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 纸张 | A4 | 页面大小 |
| 页边距 | 左/右 30mm，上/下 30mm | 页边距 |
| 正文字体 | 宋体 12pt | 中文正文 |
| 标题字体 | 黑体 | 各级标题 |
| 英文/数字字体 | Times New Roman | 英文内容 |
| 代码字体 | Consolas 五号 | 代码块 |
| 行距 | 20pt | 正文行距 |
| `doc-title` | "企业实习总结报告" | 偶数页页眉标题 |

以上均在 `utils.typ` 和 `main.typ` 中定义，按需修改。

### 封面

编辑 `cover.typ`，填写学号、姓名、专业方向、企业名称、实习岗位、指导教师等信息。

### 图表代码

在正文中使用以下函数自动编号（格式为"图 章-序号"、"表 章-序号"、"代码 章-序号"）：

```typst
// 图：图题在下
#fig("图标题", [
  #image("路径/图片.png", width: 80%)
])

// 表：表题在上
#tbl("表标题", table(
  columns: 4,
  align: center,
  ...
))

// 代码块：标题在上，黑色实线边框
#codefig("代码标题", [
  ```lang
  // 代码内容
  ```
])
```

### 参考文献

参考文献使用 GB/T 7714-2025（双语）格式。在正文中通过 `@key` 引用：

```typst
如 @lewis2020rag 所述...
引用多篇文献 #multucite("key1", "key2", "key3") 会自动合并。
```

仅被引用的条目会出现在参考文献列表中。

### 列表

```typst
// 有序列表（自动编号（1）（2）...）
+ 第一项
+ 第二项

中间打断自动编号

// 续号
#resume(3)[+ 第三项]
#resume(4)[第四项]

// 无序列表
- 一级项
  - 二级项（缩进两个空格）
```

### 标题层级

```typst
= 第一章标题          // level 1：章标题，居中，黑体小三
== 第一节标题          // level 2：节标题，顶格，黑体四号
=== 第一小节标题       // level 3：黑体四号
==== 四级标题          // level 4：黑体小四
```

每章自动另起一页，图表代码计数器随章重置。

## 自定义

- **字体**：修改 `utils.typ` 中的 `font-cn`、`font-title`、`font-en`、`font-code` 变量
- **颜色**：修改 `utils.typ` 中的颜色变量
- **页眉**：通过 `header-state.update()` 设置特殊页眉文字
- **封面图片**：替换 `images/` 目录下的 Logo 图片
